# DNA Guides Guide

- For a new guide, create a .md file in dna/doc/de|en/guides
- Write a guide short and concise, as token-saving as possible
- Write with clear instructions, addressing the reader directly,
  like a cookbook
- Where useful, reference other guides; avoid duplicating content
