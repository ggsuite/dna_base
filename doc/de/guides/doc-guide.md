# Guides guide

- Verwende den Imperativ in Überschriften and text (like this)
- Schreibe die Überschriften so, dass sie eine Zusammenfassung ergeben
- Beschreibe jeden Schritt auf einer Zeile
- Formatiere `Bildschirmelemente`, `Befehle` und `Code` als Code.
- Packe Shell-Commandos in einen bash-Code-Block

```bash
ls -la
```

- Beschreibe Schrittfolgen als Sätze mit einer Leerzeile dazwischen
- Schreibe in kurzen und klaren Sätzen
