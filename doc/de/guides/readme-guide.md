# README-Guide

- Sofern noch nicht vorhanden, erstelle eine `README.md` und eine `README.de.md`
- Lies `doc/templates/readme-template.md` und überarbeite die `README.md`
- Schreibe Knapp, kurz, klar verständlich
- Beschwere Dich im Review, wenn eine Public API geändert wurde, und diese
  nicht im README.md eingetragen wurde
- Schreibe `README.de.md`, wenn der Prompt in Deutsch verfasst ist
- Schreibe `README.en.md`, wenn der Prompt in Englisch verfasst ist
- Übersetze vor dem Publishen `README.md` nach `README.de.md` und umgekehrt
