# corepack und pnpm installieren

Stelle sicher, dass Node installiert ist, auf dem
[Mac](./install-node-mac-guide.md) oder auf
[Windows](./install-node-win-guide.md).

## Auf Mac und Linux

Führe folgende Kommandos im Terminal aus:

```bash
npm install --global corepack@latest
corepack enable pnpm
```

## Auf Windows

Drücke `Windows`

Tippe `Cmd`

Wähle `Open as administrator`

Führe folgende Kommandos aus:

```bash
npm install --global corepack@latest
corepack enable pnpm
```
