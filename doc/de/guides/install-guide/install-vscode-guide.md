# Vscode installieren

## Vscode installieren

Besuche <https://code.visualstudio.com/download>

Herunterladen und installieren

## Extensions installieren

Beim ersten Öffnen dieses Projekts wirst du gefragt, ob die
empfohlenen Workspace-Extensions installiert werden sollen. Klicke auf
`Install`.

Falls dieser Schritt nicht erscheint:

Drücke `Ctrl+Shift+P`.

Tippe `Extensions: Show Recommended Extensions` und drücke `Enter`.

Die empfohlenen Extensions werden angezeigt.

Stelle sicher, dass alle empfohlenen Extensions installiert sind.
