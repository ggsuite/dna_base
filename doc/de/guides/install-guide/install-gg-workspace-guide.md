# gg-Workspace anlegen

## Dev-Verzeichnis anlegen

```bash
mkdir -p ~/dev2
cd ~/dev2
```

## gg-Workspace initialisieren

```bash
gg do init workspace
```

## Repositories hinzufügen

```bash
gg do add dnaOrgUrl
```
