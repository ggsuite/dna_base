# DNA-Guides-Guide

- Erstelle für einen neuen Guide eine .md-Datei in dna/doc/de|en/guides
- Schreibe einen Guide kurz und knapp, möglichst tokensparend
- Schreibe mit klaren Anweisungen, in du-Form, wie ein Kochbuch
- Verwende wo sinnvoll Verweise auf andere Guides, vermeide Dinge zu doppeln
