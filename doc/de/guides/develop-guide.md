# Entwicklungs Guide

[Installiere die benötigte Software](./install-guide.md)

[Bereite einen GG Workspace vor](./install-guide/install-gg-workspace-guide.md)

Wechsele in den Workspace

```bash
cd ~/dev/ # workspace
```

Starte claude

```bash
claude
```

Starte in Claude die Entwicklung

```bash
/ticket
```

Verwende folgende Skills in Claude

```bash
/commit
/document
/push
/review
/review-heavy
/publish
/cleanup
```
