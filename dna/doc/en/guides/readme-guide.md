# README Guide

- If not yet present, create a `README.md` and a `README.de.md`
- Read `doc/templates/readme-template.md` and revise the `README.md`
- Write concise, short, clearly understandable
- Complain in the review when a public API was changed and it was not
  added to the README.md
- Write `README.de.md` when the prompt is written in German
- Write `README.en.md` when the prompt is written in English
- Translate `README.md` into `README.de.md` and vice versa before
  publishing
